# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, never in a public issue:

- {{PRIVATE_CHANNEL: GitHub private vulnerability reporting (the "Report a vulnerability" button under the Security tab) or security@example.com}}

Include what you found, how to reproduce it, and the impact you expect. We acknowledge reports within {{3}} working days and keep you informed until the issue is fixed. Please give us reasonable time to fix the problem before disclosing it.

## Scope

In scope: {{the production application and its API at https://example.com}}.
Out of scope: denial-of-service tests, social engineering, and findings in third-party services we use (report those to their owners).

## Supported versions

Only the latest release receives security fixes.
